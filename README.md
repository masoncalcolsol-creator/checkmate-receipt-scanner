# CHECKMATE
# CHECKMATE

Scan a receipt → instantly split it with people.

---

## 🚀 Live Demo

👉 https://your-checkmate-demo.vercel.app

---

## 🧠 What it does

* OCR receipt scanning
* Converts messy text into **editable item bubbles**
* Assign items to people
* Calculates totals and splits

---

## ⚡ Why it exists

OCR is never perfect.

Instead of forcing accuracy, this system **embraces correction as part of the UI** — users fix items naturally without breaking flow.

---

## 🛠 Stack

* Next.js
* Tesseract.js (OCR)
* Supabase (optional backend)

---

## 💡 Key Idea

Most apps try to eliminate errors.
CHECKMATE is built around **handling them gracefully**.

---

## 📸 Demo Flow

1. Scan receipt
2. Items appear as bubbles
3. Assign to people
4. Split + settle
